# Personal Portfolio Website

## Overview

This project is a fully accessible and semantic multi-page personal portfolio website developed using modern HTML5 standards and WCAG accessibility guidelines.

The website is designed to provide a professional online portfolio experience while ensuring accessibility, SEO optimization, responsive design, and semantic structure.

The project demonstrates best practices in front-end development using semantic HTML5, CSS3, and accessibility-first design principles.

# Accessibility Features

The website follows accessibility best practices including:

## ARIA Labels
ARIA labels are used to improve screen reader support.

## Keyboard Navigation
All interactive elements are accessible using keyboard navigation.

## Skip Navigation Link
A skip link is provided for quick access to the main content.

## Form Accessibility
All form fields include:
- Proper labels
- Required attributes
- Accessible input structure

## Focus Indicators
Visible focus outlines are added for keyboard users.

## Semantic Headings
Proper heading hierarchy is maintained throughout the website.
